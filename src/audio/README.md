# Event-driven engine audio

`EngineAudio.enable()` must be called from a click/touch gesture. AudioWorklet needs a secure context (HTTPS, or localhost). Unsupported browsers receive a clear error; there is no sample-loop fallback. `setMuted`, `setVolume`, `setQuality`, `getAnalyser` and `dispose` support UI controls and live analysis.

Call `update(state, config)` on every simulation snapshot and aggregate **all firing events since the previous snapshot**. Event times and `state.time` must use the same simulation clock in seconds. Repeated events are deduplicated. The bridge schedules actual combustion events with a 50 ms buffer, estimates the simulation/wall-clock rate for slow motion, and drops stale events following a long pause. The audio thread does not run an independent combustion oscillator. No firing events means no exhaust pulses. Stops clear queued pulses, and a 250 ms heartbeat timeout fades the whole signal when simulation stops.

The worklet excites short, smoothly attacked pressure pulses with the model's dimensionless event energy. Odd/even cylinders in V and boxer layouts feed separate bank delay lines and resonant filters. An approximate lateral bank spacing `(bore + 40 mm) × sin(bank angle / 2)` offsets collector paths by half that spacing, assuming an off-axis collector/observer. This explicit routing assumption makes firing-order bank patterns audible; actual header geometry is not measured. Inline/single layouts share symmetric paths. A damped round-trip delay line and low-order resonant filters approximate pipe reflections: sound speed is assumed 430 m/s in a hot exhaust, the first mode is `c / (4 L)`, and the return delay is `2 L / c`. Pipe diameter and muffling affect radiation, resonant balance and damping. Intake noise passes a resonant filter based on runner length. Low-level crank-angle-related mechanical motion, stochastic mechanical friction, forced-induction whine, boost-dependent wastegate noise and throttle-lift blow-off complete the signal. Crank-phase layers anchor to every snapshot. Noise is generated in the worklet; no recordings or sample assets are used.

These are acoustic approximations, not recordings or calibrated reconstructions of real engines. Exhaust gas temperature, full manifold junction impedance, microphone location, cabin transfer response, cylinder pressure traces and compressor maps are not solved. Firing order only changes sound when the cylinder's bank/path is different; evenly spaced pulses in an acoustically symmetric manifold can correctly sound alike. Worklet processing uses bounded queues and voices, band-limited pulses, high-pass/low-pass filtering, gentle saturation and a Web Audio compressor. Economy mode reduces exhaust modes and active pulse tails. Volume starts at 35%; headphone/speaker safe level still depends on the user's hardware.
